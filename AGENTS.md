# Elementales Hermanos Web

## Objetivo

Sitio web público de Elementales Hermanos, empresa familiar de San Juan, Argentina, dedicada a servicios de mantenimiento integral, renovación y restauración.

El objetivo principal del sitio es presentar los servicios, mostrar trabajos realizados y convertir visitas en consultas por WhatsApp.

## Stack

- React
- TypeScript
- Vite
- CSS
- ESLint

## Reglas de desarrollo

- Usar TypeScript.
- Crear componentes React funcionales.
- Mantener componentes simples y reutilizables.
- Priorizar código claro sobre abstracciones innecesarias.
- No agregar dependencias sin una necesidad concreta.
- No instalar librerías sin autorización.
- No crear backend para funcionalidades que puedan resolverse en frontend.
- No modificar archivos fuera del alcance solicitado.
- Mantener diseño responsive, mobile-first.
- Mantener accesibilidad básica y HTML semántico.
- Evitar overengineering.

## Diseño

La identidad visual debe partir del logo de Elementales Hermanos.

Colores principales:
- Verde oliva
- Negro / gris oscuro
- Blanco / tonos claros

El diseño debe sentirse:
- profesional
- moderno
- limpio
- confiable

Evitar una estética genérica de plantilla o una apariencia excesivamente generada por IA.

## Criterio para cambios

Antes de implementar una tarea:
- respetar la arquitectura existente;
- reutilizar componentes existentes cuando corresponda;
- evitar cambios no solicitados;
- mantener el cambio lo más pequeño posible.
